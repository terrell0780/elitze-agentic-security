# ELITZE brand naming boundary

ELITZE Agentic Security is the canonical product name.

Public product language should use ELITZE terminology and avoid exposing internal legacy orchestration names as product brands.

## Canonical public terms

- ELITZE Agentic Security
- ELITZE Security Graph
- ELITZE Global Security View
- Agent Reach
- Policy Engine
- Runtime Security
- Evidence / REO / RIO / ROE

## Rule

Internal implementation identifiers may remain where required for code compatibility, but public product copy, navigation, metadata, sales material, and buyer-facing documentation should present one coherent ELITZE brand.

Do not claim capabilities, integrations, certifications, customers, rankings, or performance results that have not been verified by the underlying control path.
