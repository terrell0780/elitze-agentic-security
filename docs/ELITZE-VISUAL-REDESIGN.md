# ELITZE visual redesign

Primary message: **See the threat. Control the path. Prove the fix.**

The public experience is visual-first and outcome-first. Detailed architecture, benchmark notes and implementation standards remain in About, Security, FAQ and repository documentation.

Core surfaces: interactive global threat surface; evidence intelligence view; compact control cards; visual benchmark scorecard; business-outcome messaging.

Integrity requirement: animation is presentation only. It must not be represented as live incidents, geographic attacks or telemetry unless backed by connected verified data. Unavailable integrations remain unavailable. Planned controls are never represented as live protection.
