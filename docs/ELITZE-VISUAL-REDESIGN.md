# ELITZE visual redesign

The public product experience is intentionally visual-first.

## Primary message

**See the threat. Control the path. Prove the fix.**

The homepage avoids leading with a scanner or pentest slogan. It presents ELITZE as a governed security control plane spanning software, cloud, identity, AI agents and runtime behavior.

## Primary surfaces

- Interactive global threat surface for connected security domains.
- Evidence-oriented intelligence view showing signal → context → decision → action → proof.
- Compact capability cards instead of long explanatory blocks.
- About and FAQ pages carry deeper product explanation.
- Benchmark page acts as a product scorecard rather than a documentation wall.

## Integrity requirements

Visual animation is presentation only. It must not be represented as live incidents, geographic attacks or telemetry unless backed by connected verified data.

Unavailable integrations remain unavailable. Planned controls are not shown as active protection.
