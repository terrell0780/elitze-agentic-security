Sara · the ELITZE assistant

An operator's agent, with the handbrake on

Sara investigates, drafts and prepares — inside the same authorization boundary as everything else. Every action that changes state stops at a named approver.

Goal → plan preview

Type what you want done. The planner composes steps and marks where a human must approve. No model call happens here.
